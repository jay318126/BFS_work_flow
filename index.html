1. First Discovery Wins
Every cell records a parent pointer only once. Because BFS visits states in order of shortest distance, the first route to reach any cell is guaranteed to be shortest. Any later discovery is ignored!
2. BFS Spreads in Layers
BFS ripples outward layer by layer (Distance 0, 1, 2...). When Goal G is reached at Layer 10, all shorter levels have already been searched. Thus, 10 moves is optimal!
